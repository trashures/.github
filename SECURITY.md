# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report it privately via the repository's **Security > Report a vulnerability** button
(GitHub private vulnerability reporting). Include what you found, how to reproduce it and the
impact you expect.

You can expect a first answer within 7 days. Trashures is an early prototype run by a very small
team, so there is no bug bounty, but we will credit you in the fix if you like.

## Scope

- The Trashures app and API at [trashures.app](https://trashures.app) and its subdomains
- Code in repositories of the [trashures](https://github.com/trashures) organization

Out of scope: denial of service, social engineering, findings in third-party services we use
(please report those to the vendor).

## Personal data

Scan records carry no personal reference; photos are only stored with explicit opt-in and deleted
after the retention period. If you find a way to link scans or photos to a person, treat it as a
vulnerability and report it as above.

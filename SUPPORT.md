# Support

- **Wrong bin or missing rule for your location?** Open an issue with the
  "Wrong or missing rule" form and add your postal code and, if possible, the official source.
- **Bug in the app?** Open an issue with the "Bug" form.
- **Security problem?** See [SECURITY.md](SECURITY.md), never a public issue.

Trashures is an early prototype, answers can take a few days.
